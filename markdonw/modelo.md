# Guía Rápida de Markdown (2025)

Esta guía contiene las etiquetas esenciales para dar formato a tus documentos de texto plano.

## 1. Títulos (Encabezados)

Se utilizan almohadillas (`#`) seguidas de un espacio. El número de almohadillas indica el nivel del título.

# Título Nivel 1 (H1)

## Título Nivel 2 (H2)

### Título Nivel 3 (H3)

## 2. Formato de Texto

Para enfatizar palabras o frases:

* **Negrita:** `**texto**` o `__texto__`
* *Cursiva:* `*texto*` o `_texto_`
* ~~Tachado:~~ `~~texto~~`

## 3. Listas

Puedes crear listas ordenadas y desordenadas fácilmente:

**Listas desordenadas (viñetas):**

* Elemento A
* Elemento B
  * Subelemento (usa sangría)

**Listas ordenadas:**

1. Primer paso
2. Segundo paso

## 4. Enlaces e Imágenes

* **Enlace:** `[Texto del enlace](https://www.ejemplo.com)`
* **Imagen:** `![Descripción de la imagen](url-de-la-imagen.jpg)`

## 5. Citas y Código

* **Citas:**

> "Esta es una cita en bloque".

* **Código en línea:** código 
* **Bloque de código:**
  \```python
  print("Hola Mundo")
  \```

## 6. Tablas

Se construyen usando barras verticales `|` y guiones `-` para separar el encabezado.
